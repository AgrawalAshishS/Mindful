# Implementation Plan: Transition to Accessibility Service-only Tracking

## 1. Requirement Analysis
Refactor the app tracking and restriction mechanism to rely solely on the **Accessibility Service**.
Remove dependency on `UsageStatsManager`.
Ensure Accessibility Service is mandatory.

## 2. Active App Detection (Fix)
*   **Problem**: `TrackingManager` currently ignores `SYSTEM_UI_PACKAGE`. If the user goes to the Home Screen (Launcher) or Recents, the previous app might still be considered "active" and counting time.
*   **Solution**:
    *   Identify the default Launcher package.
    *   When an event comes from the Launcher, treat it as a valid "app switch" (effectively stopping the previous app's session).
    *   Do not ignore `SYSTEM_UI_PACKAGE` completely, or handle it intelligently (e.g. Recents screen usually shouldn't count as usage for the app, but shouldn't count as "usage" itself either, or it counts as "System").
    *   For now, treating Launcher as "Stop Tracking Previous App" is the key.

## 3. Remove Usage Stats Dependency
*   **Android Manifest**: Remove `<uses-permission android:name="android.permission.PACKAGE_USAGE_STATS" />`.
*   **PermissionsHelper**: Remove `getAndAskUsageAccessPermission`.
*   **Flutter UI**: Update `permission_page.dart` (and `onboarding_page.dart` if needed) to remove the Usage Access step and make Accessibility mandatory.

## 4. Verification & Testing
*   **Unit Tests**: Write tests for `TrackingManager` to verify session logic, especially:
    *   App A -> App B (Session A ends, B starts).
    *   App A -> Home (Session A ends).
    *   App A -> System UI (Recents) -> App B.
*   **Manual Verification**:
    *   Install app.
    *   Check Onboarding (no Usage Access).
    *   Enable Accessibility.
    *   Open App A, wait 10s.
    *   Go Home.
    *   Open App B.
    *   Check Database (or logs) to see if App A usage was ~10s.

## 5. Execution Steps
1.  **Update `TrackingManager.kt`**:
    *   Add Launcher package detection.
    *   Handle Launcher events to stop tracking.
2.  **Update Manifest**: Remove permission.
3.  **Update `PermissionsHelper.kt`**: Remove methods.
4.  **Update Flutter UI**: `lib/ui/onboarding/permission_page.dart`.
5.  **Clean up**: Remove any dead code related to `UsageStatsManager`.
